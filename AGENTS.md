# Codex Agent Instructions

## Impeccable Is Mandatory For UI Work

For any task with even a 1% chance of touching an interface, frontend, design, UX, accessibility, responsiveness, theming, copy in UI, visual polish, layout, animation, or user-facing page/component, you MUST invoke the `impeccable` skill before reading code, asking clarifying questions, proposing changes, or editing files.

This is non-negotiable.

### Required Workflow

1. Check for the skill first. `impeccable` is available via the Skill tool. Invoke it by name: `impeccable`.
2. Do not rely on memory of the skill. Load the actual skill every session because it evolves.
3. If a sub-command applies, pass it:
   - For "review this", "score this", "critique this", or heuristic UX review: invoke `impeccable critique`.
   - For accessibility, performance, responsive, theming, or anti-pattern checks: invoke `impeccable audit`.
   - For fix or improvement work, invoke the matching refine command such as `polish`, `harden`, `distill`, `clarify`, `adapt`, `optimize`, `layout`, `typeset`, `colorize`, `animate`, or `delight`.
4. Before acting, announce exactly: `Invoking impeccable to [purpose].`
5. Follow the skill's instructions exactly, including its setup steps, scoring tables, AI-slop test, absolute bans, and product-vs-brand register guidance.
6. Do not skip the skill by rationalizing that a task is simple, obvious, or already understood.
7. If the Skill tool reports that `impeccable` is unavailable, stop and tell the user it is not installed. Do not improvise a substitute.

These instructions apply before all other UI/design/frontend work in this repository.
